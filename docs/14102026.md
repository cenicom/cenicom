Criterio de aceptación: con dos procesos concurrentes, la secuencia debe quedar inicializada una sola vez y las sedes confirmadas deben tener códigos únicos, sin pérdida de incrementos.
El reintento debe distinguir el conflicto de unicidad de otros errores de base de datos. No debemos ocultar excepciones ajenas a la inicialización.
Decisión propuesta: reintento automático, limitado y específico para la inicialización concurrente. Todavía no implica modificar código: primero incorporamos esta regla al contrato y definimos cómo demostrarla mediante pruebas.
