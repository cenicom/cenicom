Siguiente paso: verificar el sistema de permisos existente
Antes de definir el contrato definitivo, debemos conocer qué está implementado para no duplicar mecanismos ni inventar permisos incompatibles con CENICOM.

La revisión se limitará a:
1. Catálogo actual de permisos y roles.
2. Asignación de permisos a roles y usuarios.
3. Cargador y registro de permisos de los módulos.
4. Evidencia de pruebas existentes.
Después elaboraremos una matriz rol → permiso → alcance → operación → auditoría, distinguiremos lo reutilizable de lo pendiente y presentaremos el contrato para aprobación.

En paralelo, seguimos con el cierre de las brechas confirmadas de Fase 4. No modificamos código ni migraciones todavía.
