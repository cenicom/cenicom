 10.9.3 — Module → CRUD

El objetivo ahora es conectar la infraestructura CRUD existente con la arquitectura modular, sin volver a tocar CN-GUI ni rehacer componentes.

La dirección correcta es:

Module → CRUD Definition → Registry/Discovery → CRUD infrastructure → GUI

Y conviene mantener la misma filosofía que ya usamos en Navigation y Permissions:

Definir el contrato de la declaración CRUD de un módulo.
Crear el DTO/Definition correspondiente.
Crear Registry/Registrar, si la arquitectura lo requiere.
Descubrir/cargar las definiciones del módulo.
Registrar las definiciones durante el bootstrap del módulo.
Conectar la definición con la infraestructura CRUD existente.
Probar:
contrato;
registro;
múltiples módulos;
ausencia de módulos;
integración;
resolución desde container;
finalmente, render/uso desde GUI.
