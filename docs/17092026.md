Siguiente maniobra

Antes de cambiar ModuleData, haría una última búsqueda muy pequeña para comprobar si alguien depende directamente de migrationFilename() y para no introducir una modificación con efectos ocultos:

printf '\n--- MIGRATION FILENAME USAGES ---\n'

grep -R -n \
  --exclude-dir=vendor \
  --exclude-dir=node_modules \
  "migrationFilename(" \
  app tests

printf '\n--- MIGRATION FILE USAGES ---\n'

grep -R -n \
  --exclude-dir=vendor \
  --exclude-dir=node_modules \
  "migrationFile(" \
  app tests

Si esa búsqueda confirma lo que esperamos, ya tendríamos evidencia suficiente para hacer una corrección mínima en ModuleData y cerrar el contrato con tests, sin tocar el resto del pipeline.
