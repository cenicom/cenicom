Protocolo de continuidad
1. Una decisión aprobada se registra.
2. Una evidencia presentada se conserva como referencia.
3. Una etapa cerrada no se vuelve a revisar.
4. Solo se reabre una decisión cuando aparece una contradicción técnica o una nueva evidencia que afecta directamente su validez.
5. Cada etapa termina con un resultado verificable antes de pasar a la siguiente.
   
   Principio rector:
Evidencia → contrato → impacto → corrección → evidencia.

- Datos existentes de genders.
- Migraciones ajenas a EST-01.
