Un punto técnico antes de escribir las pruebas

Hay una particularidad: campuses.address_id exige una fila real de addresses, y addresses a su vez exige country_id, state_id y city_id válidos.

Por eso no debemos inventar un factory de Address ni insertar datos arbitrarios. Ya tenemos evidencia de que las tablas geográficas importadas contienen una combinación válida country=1 / state=1 / city=1.

El siguiente paso puede ser entonces diseñar la prueba usando datos mínimos reales de MySQL, siguiendo el patrón ya demostrado por ImportedTablesGeographicReferenceTest.

Si estás de acuerdo, el siguiente movimiento es C-02.13.3 — implementación de las pruebas de persistencia, probablemente como una prueba Feature específica de Campus, sin introducir todavía ninguna clase funcional de Campus.
